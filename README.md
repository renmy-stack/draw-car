# ドローカーレース

タイヤを指で描いて、障害物コースを走らせるレースゲーム。ゴールまでのタイムで友達と勝負。

- 遊ぶ: https://renmy-stack.github.io/draw-car/
- iPhone / Android の Safari・Chrome で開くだけ。インストール不要

## 遊び方
1. 下の白いパッドに、タイヤの形を1本の線で描く（うしろ・まえ、それぞれ）
2. 描いた瞬間にスタート。ゴールまでのタイムを競う
3. 走っている途中でも描き直せる。障害物に合わせてタイヤを変えるのがコツ
   - 大きい丸: 速い。段差にも強い。でもトンネルは通れない
   - 小さい丸: トンネルを通れる。段差に弱い
   - 四角・星・ギザギザ: 壁をよじ登れる。氷ではすべる
4. ゴールしたら「シェア」で、描いたタイヤとタイムの画像を LINE や X に送れる

コースは3つ（はらっぱ / とうげ / まよなか）。自己ベストは端末に保存される。

## ファイル
- `index.html` / `style.css` … 画面
- `physics.js` … コース生成と物理（DOM に依存しない。Node でも動く）
- `game.js` … 描画パッド・レース進行・シェア
- `test_physics.js` … `node test_physics.js` で、代表的なタイヤ形ごとの完走可否とタイムを一覧
- `test_sections.js` … `node test_sections.js` で、区間ごとにどの形が通れるかの表

## ローカルで試す
```
python -m http.server 8092
```
`http://127.0.0.1:8092/` を開く。コンソールで `ff(秒)` を実行すると早送りできる。

## コースの区間
おか / でこぼこ / かいだん / おおなみ / みぞ / おおみぞ / ハードル / のこぎり / こおり（すべる登り坂）/ がけ / きゅうざか / どろ（遅くなる）/ ベルト（床が逆に流れる）/ かべ / トンネル（天井が低い）

区間の数値は `physics.js` の `COURSES`。物理の定数（トルク `POWER`・回転上限 `WMAX` など）も同じファイルの先頭。

# ドローカーレース

タイヤを指で描いて、障害物コースを走らせるレースゲーム。ゴールまでのタイムで友達と勝負。

- 遊ぶ: https://renmy-stack.github.io/draw-car/
- iPhone / Android の Safari・Chrome で開くだけ。インストール不要

## 遊び方
1. 下の白いパッドに、タイヤの形を1本の線で描く（うしろ・まえ、それぞれ）
2. 描いた瞬間にスタート。ゴールまでのタイムを競う
3. 走っている途中でも描き直せる。障害物に合わせてタイヤを変えるのがコツ
   - 大きい丸: 速い。段差にも強い。でもトンネルは通れない
   - 小さい丸: トンネルを通れる。段差に弱い
   - 四角・星・ギザギザ: 壁をよじ登れる。氷ではすべる
   - 前後で大きさが違うと車体が傾く（車体は坂なりに傾き、±22° まで。転倒はしない）
   - タイヤの大きさに上限はない。でも「もん」は大きすぎると頭がつかえ、「くさったはし」は大きすぎる（半径 72 超）と板が抜けて水に落ちる
4. ゴールしたら「シェア」で、描いたタイヤとタイムの画像を LINE や X に送れる

コースは3つ（はらっぱ / とうげ / まよなか）。自己ベストは端末に保存される。

## ゴースト
レース中、自己ベストの走りが半透明の金色の車（ベスト）として一緒に走る。ゴール後に何秒勝ったか負けたかが出る。
（CPU「おてほん」と、URL で受け取る「ともだち」も作ったが、オーナーの判断でベストだけにした。`physics.js` の `idealEvents` / `encodeGhost` / `decodeGhost` は残してあるので、戻すときは `game.js` の `ghostDefs` とシェア文を変えるだけ）

ゴーストは「描いた線」と「描き替えた物理ステップ番号」だけを記録し、同じ物理で走らせ直して再現する（`physics.js` の `makeRunner`）。
そのため物理は `Math.sin/cos/hypot` を使わず、四則と sqrt だけで組んである（端末やブラウザが違っても同じ結果になるように）。
ゴーストはそれぞれ自分のコースを持つので、ゴーストがくさった橋を割っても自分の橋は割れない。
描いた線は 0.5px に丸めてから使う（URL に入れる形と、いま走る形を同じにするため）。
物理やコースの数値を変えたら `PHYS_VERSION` を上げる。古いゴーストは読めなくなる（再現できないので捨てる）。

## ファイル
- `index.html` / `style.css` … 画面
- `physics.js` … コース生成と物理（DOM に依存しない。Node でも動く）
- `game.js` … 描画パッド・レース進行・シェア
- `test_physics.js` … `node test_physics.js` で、代表的なタイヤ形ごとの完走可否とタイムを一覧
- `test_sections.js` … `node test_sections.js` で、区間ごとにどの形が通れるかの表
- `test_ghost.js` … `node test_ghost.js` で、ゴースト再生の完全一致・URL エンコード往復・橋の独立性・おてほんの完走を確認

## ローカルで試す
```
python -m http.server 8092
```
`http://127.0.0.1:8092/` を開く。コンソールで `ff(秒)` を実行すると早送りできる。

## コースの区間
おか / でこぼこ / かいだん / おおなみ / みぞ / おおみぞ / ハードル / のこぎり / こおり（すべる登り坂）/ がけ / きゅうざか / どろ（遅くなる）/ ベルト（床が逆に流れる）/ かべ / トンネル（天井が低い）/ もん（段差 72 のすぐ上に天井 110。登れて、かつ大きすぎないタイヤだけ通れる）/ くさったはし（タイヤの半径が 72 を超えると板が抜けて、深さ 80 の水に落ちる。水の中は遅い）

区間の数値は `physics.js` の `COURSES`。物理の定数（トルク `POWER`・回転上限 `WMAX`・傾きの上限 `TILT_MAX` など）も同じファイルの先頭。

壁・もんの段差 72 と傾きの上限 22° は組で決めてある。丸いタイヤは壁に当たると後輪を支点に鼻を上げるので、前輪の届く高さは「42 + 60×sin(上限角)」≒ 67 になり、72 の段差は越えられない（半径 68 まで）。四角・星は角を引っかけて 3〜4 秒で登る。タイヤの大きさに上限がないので、丸 80 は 72 の壁を越えてしまう。だから 3 コースの壁は「もん」（天井 110 つき）にしてある。四角 60〜80・星 65〜80 は通れ、丸は大きさに関係なくつかえる。

パッドは 300×180 で軸は y=100。軸を中心に描ける半径は下に 80・上に 100 まで。くさったはしの限界（半径 72）は「パッドの下いっぱいまで描いた丸」だけが落ちる大きさ。判定は軸からいちばん遠い点の距離（`makeCar` の `reach`）で、線の長さ（重さ）ではない。線の長さで判定すると星やギザギザが不利になるため。
